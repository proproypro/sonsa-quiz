# 손해사정사 1차 데일리 기출 (sonsa-quiz)

보험개발원이 공개한 손해사정사 1차 기출문제로 매일 랜덤 문제를 푸는 정적 웹앱입니다. 서버가 필요 없고, `index.html`을 열면 바로 동작합니다. 학습 기록은 브라우저 localStorage에 저장됩니다.

## 기능

- **오늘의 문제**: 날짜를 시드로 고정된 랜덤 세트(기본 30문항, 3과목 균형). 중간에 나가도 진행 상황이 저장됩니다.
- **연습 모드**: 과목·연도·문항 수를 골라 랜덤 출제.
- **모의고사**: 과목당 40문항 × 3과목 = 120문항, 120분 타이머, 과목 40점·평균 60점 합격 판정.
- **오답노트**: 틀린 문제를 모아 다시 풀기. 맞히면 목록에서 빠집니다.
- **통계**: 연속 학습일, 과목별 정답률, 최근 세트 기록.
- 설정에서 "틀린 문제·안 푼 문제 우선 출제"를 켜면 약점 위주로 뽑습니다.

## 시험 정보 (제49회 기준)

| 항목 | 내용 |
|---|---|
| 과목 | 보험업법, 보험계약법(상법 보험편), 손해사정이론 (재물은 영어 추가, 공인영어로 대체) |
| 문항 | 과목당 40문항, 객관식 4지선다 |
| 시간 | 1교시 80분(보험업법·보험계약법), 2교시 40분(손해사정이론) |
| 합격 | 매 과목 40점 이상, 전 과목 평균 60점 이상 |

## 실행

폴더에서 `index.html`을 더블클릭하거나, 로컬 서버로 띄웁니다.

```bash
python -m http.server 8080
```

## 기출문제 넣기

처음에는 `data/seed_questions.json`의 예시 문제 24개만 들어 있습니다. 실제 기출문제는 아래 순서로 추가합니다.

1. 보험개발원 기출문제 자료실에서 회차별 zip을 내려받습니다.
   https://certi.kidi.or.kr:10443/exam/library/past-list
   (제49회 `basic_49_1_new.zip`, 제48회 `BASIC_48_1_new.zip`, 제47회 `basic_47_1_new.zip` …)
2. 압축을 풀어 `data/raw/48회/` 같은 폴더에 넣습니다. HWP 파일이면 한컴오피스에서 PDF로 저장합니다.
   파일명에 과목명(보험업법/보험계약법/손해사정이론)이 들어가야 자동 인식됩니다. 정답 파일명에는 "정답" 또는 "답안"이 포함되어야 합니다.
3. 변환합니다(보험개발원 PDF 전용 스크립트).

```bash
python tools/import_kidi.py data/raw/50 --round 50 --year 2027
```

   일반 PDF는 `tools/import_pdf.py`를 씁니다.

```bash
python tools/import_pdf.py --year 2025 --round 48 --auto data/raw/48회
```

   파일 하나씩 지정할 수도 있습니다.

```bash
python tools/import_pdf.py --year 2025 --round 48 --subject 보험계약법 --questions data/raw/48회/보험계약법.pdf --answers data/raw/48회/정답.pdf
```

4. 출력되는 검수 리포트(보기 4개 미만 문항, 정답 누락)를 보고 `data/bank/*.json`을 손봅니다. 정답이 0인 문항은 출제에서 제외됩니다.
5. 수정 후에는 병합만 다시 실행합니다.

```bash
python tools/import_pdf.py --build
```

PDF가 2단 편집이면 `--columns 2`를, 파싱이 이상하면 `--dump out.txt --questions 파일.pdf`로 추출 텍스트를 확인하세요. 파이썬 패키지는 `pymupdf`가 필요합니다.

## 문제 데이터 형식

```json
{
  "id": "2025-48-1-12",
  "year": 2025, "round": 48, "subject": "보험계약법", "num": 12,
  "question": "문제 본문",
  "choices": ["보기1", "보기2", "보기3", "보기4"],
  "answer": 3,
  "explanation": "해설(선택)",
  "source": "보험개발원 제48회"
}
```
